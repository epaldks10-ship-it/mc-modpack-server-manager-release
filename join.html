마인크래프트 서버에 초대받았어요

친구가 연 모드팩 서버예요. 아래 순서대로 하면 돼요.

휴대폰에서는 설치할 수 없어요. 이 링크를 PC로 보내서 PC에서 열어 주세요.
초대 코드가 없거나 잘린 링크예요. 방장에게 [친구 초대 링크 복사]로 링크를 다시 받아 주세요.

1

프로그램을 받아요. 버튼을 누르면 초대 코드도 같이 복사돼요.

받은 파일 오른쪽 클릭 → [압축 풀기] → 모드팩서버관리.exe 실행. 파란 경고 창이 뜨면 [추가 정보] → [실행].
2

프로그램을 켜면 초대 코드가 저절로 들어가요. [친구 서버 들어가기] 탭에서 ▶ 설치하고 게임 켜기를 눌러요.

이미 프로그램이 있으면 이 버튼만 누르고 프로그램을 켜세요. 코드가 안 들어가 있으면 [친구 서버 들어가기] 탭 칸에 붙여 넣으세요 (Ctrl+V). CurseForge 모드팩이라 프로그램이 모드팩을 대신 받지 않고, CurseForge 앱으로 설치하기 창을 띄워서 순서를 알려 줘요. (앱 받기 → 같은 버전 설치)
3

방장이 추가한 모드를 넣어요.

  • [자동] 0개: 프로그램이 Modrinth에서 알아서 받아서 넣어요. 할 일 없어요.
  • [링크] 0개: Modrinth에 없는 모드라 원본 페이지에서 직접 받아요. 설치가 끝나면 추가 모드 직접 받기 창이 떠요. 아래 링크(또는 창의 [선택한 모드 페이지 열기])에서 이 마인크래프트 버전에 맞는 .jar 파일을 받아서, 창의 [넣을 폴더 열기]로 열리는 직접_받은_모드 폴더에 넣고 [다 넣었어요. 게임 켜기]를 눌러요. 다음부터는 게임을 켤 때마다 알아서 들어가요.
    3

    런처가 열리면 설치 목록에서 모드팩: …을 고르고 [플레이] → 멀티플레이 → 서버 접속. (서버는 목록에 이미 들어 있어요)

    방장에게 내 마인크래프트(자바) 닉네임을 꼭 알려 주세요. 화이트리스트에 있어야 들어갈 수 있어요.

    프로그램 없이 직접 하기 (CurseForge·Modrinth 앱, Mac)
    1

    모드팩 앱을 받아요.

    CurseForge 앱 받기 Modrinth 앱 받기
    설치하고 켠 다음 Minecraft를 골라요. 앱 설정에서 게임 메모리(램)를 6~8GB로 올려 주세요.
    2

    앱에서 모드팩 -을(를) 검색해서 버전 -(으)로 설치해요.

    모드팩 공식 페이지 열기
    버전이 다르면 접속이 안 돼요.
    3

    방장이 추가한 모드를 넣어요. 각 링크에서 이 마인크래프트 버전에 맞는 .jar 파일을 받아서, 게임을 끈 상태에서 모드팩의 mods 폴더에 넣어요.

      CurseForge 앱: 모드팩 오른쪽 위 점 3개 → Open Folder → mods. Modrinth 앱: 모드팩 화면에서 폴더 열기 → mods.
      3

      앱에서 Play → 마인크래프트가 켜지면 멀티플레이 → 서버 추가 → 주소 방장에게 물어보세요

      방장에게 내 마인크래프트(자바) 닉네임을 꼭 알려 주세요. 화이트리스트에 있어야 들어갈 수 있어요.

      이 페이지는 초대 코드를 어디에도 보내지 않아요. 코드는 링크의 # 뒤에만 있고, 이 PC 안에서만 풀어서 보여 줘요. 모드팩과 모드는 언제나 공식 사이트(CurseForge, Modrinth, 모드 제작자 페이지)에서 받아요.
