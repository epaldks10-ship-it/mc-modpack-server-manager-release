이 프로그램 하나로 서버를 만들고, 켜고, 친구를 들여보내고, 모드와 설정을 바꿀 수 있어요. 파일을 직접 열어서 고칠 일은 없어요.

    카톡, 디스코드, 구글 드라이브, 원드라이브 등에 모드팩서버관리.exe가 있는 폴더를 올리면 안 돼요. 우리 월드, 화이트리스트, 서버 설정이 다 들어 있어요.
    친구에게 보내도 되는 건 딱 두 가지예요. ① [친구 접속 안내]의 글, ② 친구용_추가모드 폴더. → 4번

1. Playit 연결 (처음 한 번만) 언제든지

Playit은 친구들이 들어올 인터넷 주소를 만들어 주는 무료 서비스예요. 공유기 설정은 필요 없어요.

  1. 내 서버 탭 왼쪽의 Playit 연결 설정을 눌러요.
  2. 비밀 키 만드는 페이지 열기를 누르고 playit.gg에 로그인해요. 계정이 없으면 구글 계정 등으로 가입해요(무료).
  3. 화면 안내를 따라가면 비밀 키(Secret Key)가 나와요. 복사해요.
  4. 설정 창의 칸에 붙여 넣고 저장을 눌러요. 키는 이 PC의 내 Windows 계정에서만 풀리게 암호화돼서 저장돼요.
  5. [터널 만들기] 터널 페이지 열기 → Add Tunnel을 눌러요. 종류 Minecraft Java, 주소 127.0.0.1, 포트 25565로 만들어요.
  6. 터널 목록의 어쩌구.joinmc.link 같은 주소가 우리 서버 주소예요. 설정 창의 자동으로 가져오기를 누르면 프로그램이 Playit에 물어봐서 맨 아래 칸에 넣어 줘요. (안 되면 주소를 복사해서 붙여 넣고 저장)
    프로그램을 켤 때와 친구 접속 안내를 열 때도 다시 확인하니까, 터널을 새로 만들어 주소가 바뀌어도 알아서 따라가요.
  7. 이제 왼쪽 아래 친구에게 줄 주소 복사로 언제든 주소를 복사할 수 있고, 친구 접속 안내에도 주소가 자동으로 들어가요. → 다음: 4번 ②에서 친구에게 보내요

이제 ▶ 친구랑 하기로 켜면 Playit도 같이 켜지고, 서버를 끄면 같이 꺼져요. 왼쪽 아래에 Playit: 실행 중이 보이면 정상이에요. 어떤 모드팩 서버를 켜든 같은 주소를 써요. ▶ 친구랑 하기로 켜 둔 채로 키를 저장해도 서버를 끄지 않고 바로 연결돼요.

2. 서버 만들기 언제든지

  1. 새 서버 만들기 탭에서 왼쪽 목록의 모드팩을 눌러요. (어떤 걸 고를지 모르겠으면 아래 표의 Better MC)
  2. 버전을 골라요. 친구들도 꼭 같은 버전을 설치해야 해요. 테스트판이 붙은 버전은 피하세요.
  3. 서버 이름은 자동으로 채워져요. 바꾸려면 영어와 숫자로만 쓰세요.
  4. 서버 메모리는 권장값으로 채워져요. 이 컴퓨터에서 게임도 같이 하면 6GB 정도가 적당해요. 나중에 바꿀 수 있어요. → 6번 ③
  5. 이용약관(EULA) 동의를 체크하고 서버 만들기를 눌러요.
  6. 아래 칸에 진행 상황이 나와요. 작은 팩은 몇 분, 큰 팩(ATM, Medieval MC)은 10~20분 걸려요. "완료!"가 나오면 자동으로 내 서버 탭으로 넘어가요. → 다음: 3번

만드는 동안 프로그램을 닫으면 중단돼요. 그래도 괜찮아요. 다음에 프로그램을 켜면 끝나지 못한 폴더를 알아서 정리하니까, 같은 이름으로 다시 만들면 돼요.

목록에 없는 모드팩 넣기

  1. 목록 아래 + 모드팩 추가를 눌러요.
  2. Modrinth 모드팩: 모드팩 페이지의 주소(예: https://modrinth.com/modpack/...)를 그대로 붙여 넣어요.
  3. CurseForge 모드팩: 모드팩 페이지 오른쪽 About Project 칸의 Project ID 숫자를 넣어요. (CurseForge는 주소로는 찾을 수 없어서 숫자가 필요해요)
    CurseForge는 모드팩 만든 사람이 서버팩을 올려 둔 경우에만 넣을 수 있어요. 새 버전은 하루에 한 번, 목록에서 고를 때 확인해요.
  4. 목록에 ★ 표시로 생겨요. 그다음은 위의 2~6번과 똑같아요. 친구 접속 코드에도 모드팩 정보가 같이 들어가서, 친구도 그대로 들어올 수 있어요.
  5. 필요 없어지면 고르고 목록에서 빼기. (이미 만든 서버는 그대로 있어요)

3. 서버 켜고 끄기

  1. 내 서버 탭 왼쪽 목록에서 서버를 골라요.
  2. 둘 중 하나를 눌러요.
    • ▶ 친구랑 하기: 서버를 열고 Playit도 같이 켜요. 친구들은 Playit 주소로 들어와요. (Playit 연결이 아직이면 → 1번)
    • ▶ 혼자 하기: 같은 월드를 내 컴퓨터에서만 열어요. 다른 사람은 못 들어와요. 친구랑 하던 월드를 혼자 이어서 할 때 쓰세요.
  3. 위쪽 막대와 글자로 진행 상황과 남은 시간이 보여요. 초록색으로 "서버 열림!"이 나오면 다 켜진 거예요. 소리도 한 번 나요.
  4. [게임 켜기] 왼쪽 ▶ 마인크래프트 켜기를 눌러요. CurseForge 앱은 필요 없어요.
    • 서버와 똑같은 모드팩 게임을 준비해요. 처음엔 몇 분 걸리고, 다음부터는 바로 넘어가요. 모드팩을 업데이트하거나 모드를 넣으면 게임도 알아서 맞춰요.
    • 공식 마인크래프트 런처가 열려요. [플레이] 옆 설치 목록에서 모드팩: ...을 고르고 플레이.
    • 게임이 켜지면 멀티플레이 → 맨 위 서버이름 (내 서버) → 서버 접속. 주소는 이미 들어 있어요.
    • 로그인은 런처에서 내 마이크로소프트 계정으로 해요. 이 프로그램은 비밀번호를 다루지 않아요.
    • 런처가 없으면 다운로드 페이지를 열어 줘요. 설치하고 한 번 로그인한 다음 다시 누르세요.
  5. 끌 때는 ■ 서버 끄기를 누르고 "꺼짐"이 될 때까지 기다려요.

4. 친구 들여보내기

① 화이트리스트에 추가 언제든지

  1. 친구 추가를 눌러요.
  2. 닉네임(마인크래프트 자바 계정 이름)을 입력하고 확인을 눌러요. 처음엔 내 닉네임부터 넣으세요.
  3. 서버가 켜져 있으면 바로 추가되고, 꺼져 있으면 다음에 서버가 열릴 때 자동으로 추가돼요.
  4. 깜빡하고 안 넣었어도 괜찮아요. 친구가 들어오려다 막히면 프로그램이 "지금 추가할까요?"라고 물어봐요. 아는 친구일 때만 예를 누르세요.

② 친구에게 접속 안내 보내기 언제든지

  1. 친구 접속 안내를 눌러요.
  2. 글 전체 복사 → 카톡이나 디스코드에 붙여 넣어요. 1번 ⑥에서 주소를 저장해 뒀다면 주소도 글 안에 들어 있어요.
  3. 모드를 따로 추가했다면 친구용 추가모드 폴더 열기 → 폴더를 압축해서 같이 보내요.

③ 친구가 할 일: 제일 쉬운 방법 (안내 글 맨 위에 적혀 있어요)

  1. 안내 글의 링크에서 이 프로그램을 받아 압축을 풀고 모드팩서버관리.exe를 켜요.
  2. 친구 서버 들어가기 탭 → 받은 안내 글을 통째로 붙여 넣기 → ▶ 설치하고 게임 켜기.
  3. 같은 모드팩, 같은 버전, 방장이 추가한 모드까지 알아서 깔려요. 런처가 열리면 모드팩: ... → 플레이 → 멀티플레이 → 서버 접속.
  4. 다음부터는 같은 탭의 설치해 둔 친구 서버에서 ▶ 게임 켜기만 누르면 돼요. 방장이 모드팩을 업데이트했다면 새 안내 글을 다시 붙여 넣어요.

④ 친구가 할 일: 앱으로 직접 하는 방법

  1. CurseForge 앱 또는 Modrinth 앱을 설치해요.
  2. 안내 글의 모드팩을 검색해서 같은 버전으로 설치해요.
  3. 앱 설정에서 메모리(램)를 6~8GB로 올려요.
  4. 추가 모드가 있으면 게임을 끈 상태에서 받은 파일을 모드팩의 mods 폴더에 넣어요. (앱에서 모드팩 오른쪽 위 점 3개 → Open Folder → mods)
  5. 게임 실행 → 멀티플레이 → 서버 추가 → 받은 Playit 주소 입력 → 접속.

5. 모드 추가 / 빼기 서버 끈 상태에서

  1. 서버를 끄고 백업해요. → 7번 ①
  2. 모드 추가 / 관리를 눌러요.
  3. 검색 칸에 모드 이름(영어)을 넣고 검색. 이 서버에 맞는 모드만 나와요.
  4. 모드를 고르고 선택한 모드 추가. 필요한 선행 모드도 자동으로 같이 받아요.
  5. 서버를 켜서 "서버 열림!"까지 가는지 확인해요. → 3번 (안 켜지면 → 10번)
  6. 친구들에게 추가 모드 파일을 보내요. → 4번 ② 의 3

  • Modrinth에 없는 모드는 내 컴퓨터의 .jar 파일 추가로 넣을 수 있어요. 마인크래프트 버전과 로더가 맞는지는 직접 확인해야 해요.
  • 한 번에 하나씩 넣고 켜 보세요.

6. 서버 설정 바꾸기 서버 끈 상태에서

① 난이도, 게임 모드, 최대 인원 등

  1. 서버를 꺼요.
  2. 서버 설정 (난이도, 인원 등)을 눌러요.
  3. 바꾸고 싶은 항목을 고르고 저장. 다음에 켤 때부터 적용돼요. (서버가 켜져 있으면 볼 수만 있고 저장은 막혀 있어요)

② 렉이 심할 때

①의 창에서 시야 거리와 움직이는 거리를 6~8로 낮춰 보세요. 그래도 심하면 ③으로 가요.

③ 서버 램(메모리) 바꾸기

  1. 서버를 꺼요.
  2. 오른쪽 위 서버 램(GB) 칸의 숫자를 바꾸고 램 바꾸기.
  3. 다음에 켤 때부터 적용돼요.

같은 PC에서 게임도 하면 컴퓨터 전체 램의 절반을 넘기지 않는 게 좋아요(게임에도 6~8GB가 필요해요).

④ 모드팩 업데이트

새 버전이 나오면 왼쪽 버튼이 노란색 "모드팩 업데이트: 새 버전 있음!"으로 바뀌어요.

  1. 서버를 끄고 노란 버튼을 눌러요.
  2. 안내를 읽고 예. 진행 상황은 아래쪽 로그 칸에 나와요.
  3. 끝나면 친구들에게 모드팩을 같은 새 버전으로 업데이트하라고 알려 주세요. → 4번 ②
월드, 화이트리스트, 설정, 직접 추가한 모드는 그대로 옮겨요. 시작 전에 월드를 자동으로 백업하고, 예전 서버는 servers_old에 보관해요. 중간에 끊기면 다음에 프로그램을 켤 때 원래대로 되돌려요.

7. 백업과 월드 관리 서버 끈 상태에서

백업 / 월드 관리를 누르면 아래 기능이 다 있어요.

① 지금 백업하기

서버를 끌 때마다 자동으로 백업해요 (auto_로 시작하는 것, 최근 5개만 남겨요). 끈 다음 상태가 잠깐 "자동 백업 중"이 됐다가 "꺼짐"으로 바뀌어요.

모드나 설정을 바꾸기 전에는 지금 백업하기도 한 번 눌러 두세요. 직접 만든 백업은 자동으로 지워지지 않아요.

② 예전으로 되돌리기

  1. 목록에서 돌아가고 싶은 때의 백업을 골라요.
  2. 선택한 백업으로 되돌리기 → 예. 지금 월드도 되돌리기 전에 자동으로 백업돼서, 마음이 바뀌면 그걸로 다시 되돌리면 돼요.

③ 월드 새로 만들기

월드 새로 만들기 (처음부터) → 시드는 모르면 비워 두고 확인. 지금 월드는 자동 백업돼요. 다음에 서버를 켤 때 새 월드가 만들어져요.

8. 다른 PC로 옮기기 서버 끄고 프로그램도 닫은 상태에서

  1. 서버를 끄고 프로그램을 닫아요.
  2. 모드팩서버관리.exe가 있는 폴더 전체를 USB나 외장하드로 새 PC에 복사해요. (인터넷으로 옮기지 마세요. 맨 위 주의사항 1)
  3. 새 PC에서 모드팩서버관리.exe를 실행해요.
  4. Playit 키는 예전 PC에서만 풀려서, 왼쪽 아래에 "키를 다시 넣어 주세요"가 나와요. → 1번 ①~④만 다시 하면 돼요 (터널과 주소는 그대로예요)
  5. 옮긴 다음에는 예전 PC에서 켜지 마세요.

9. 보안 언제든지

서버를 켤 때마다 안전한 설정(정품 인증, 화이트리스트, 원격 관리 끄기, 내 PC 안에서만 접속 받기)을 자동으로 맞춰요. 따로 할 일은 없어요. 상태는 보안 점검에서 볼 수 있어요.

  • 친구들에게는 Playit 주소만 알려 주세요. 우리 집 IP 주소는 알려 주지 마세요.
  • 공유기 포트포워딩은 하지 마세요. 필요 없고, 하면 집 IP가 드러나요.
  • 처음 서버를 켤 때 Windows 방화벽 창이 뜨면 [취소]를 눌러도 돼요.
  • 모드는 Modrinth, CurseForge 공식 사이트에서만 받으세요.
  • 프로그램은 켤 때 새 버전이 있으면 자동으로 업데이트해요. 개발자의 디지털 서명이 맞는 파일만 설치해요.

공격(디도스)을 받는 것 같을 때 (갑자기 렉, 다들 접속이 끊김)

  1. ■ 서버 끄기 → "꺼짐"이 될 때까지 기다려요.
  2. 보안 점검 → playit.gg 터널 페이지 열기 → 지금 쓰던 터널을 지워요(Delete).
  3. → 1번 ⑤단계로 가서 터널을 새로 만들어요. 새 주소가 생겨요.
  4. → 4번 ②로 가서 믿는 친구에게만 새 주소를 보내요.
  5. ▶ 친구랑 하기로 다시 켜요. 예전 주소는 없어졌으니 공격이 더는 닿지 않아요.

10. 문제 해결

이런 일이 생기면이렇게 하세요
로그에 빨간 글씨나 ERROR가 많아요모드가 많으면 원래 그래요. "서버 열림!"까지 가면 정상이에요.
"켜지다가 멈췄어요"화면 전용 모드 때문이면 "이 모드를 빼고 다시 켤까요?"라고 물어봐요 → 예.
메모리 문제면 위쪽 글에 나온 대로 → 6번 ③에서 램을 바꾸고 다시 켜요.
그 밖의 경우 서버 폴더 열기 → crash-reports의 최신 파일을 도와줄 사람에게 보여 주세요.
"다른 서버가 이미 켜져 있어요"서버는 한 번에 하나만 켤 수 있어요. 켜져 있는 서버를 먼저 끄세요. 이 프로그램 밖에서 켜진 서버라면 프로그램을 닫았다가 다시 켜면 찾아서 꺼 줘요.
"서버가 켜져 있어서 지금은 할 수 없어요"■ 서버 끄기 → "꺼짐"이 된 뒤 다시 눌러요.
나도 못 들어가요 / "You are not white-listed"→ 4번 ①에서 닉네임 추가. 내 컴퓨터에서는 주소가 127.0.0.1예요.
친구가 접속을 못 해요먼저 콘솔 창에 ※로 시작하는 안내가 떴는지 보세요. 화이트리스트, 모드팩 버전, 마인크래프트 버전, 로그인 문제는 이유와 할 일을 알려 줘요. 안내가 없으면 차례대로 확인해요. ① 상태가 "서버 열림!"인가 ② ▶ 친구랑 하기로 켰나(혼자 하기 X) ③ 왼쪽 아래가 "Playit: 실행 중"인가 (아니면 → 1번) ④ 친구가 주소를 맞게 넣었나 ⑤ 친구 닉네임을 추가했나 (→ 4번 ①)
"Mod rejections", "mismatched mods"친구의 모드팩 버전이나 추가 모드가 서버와 달라요. → 4번 ③을 친구와 같이 다시 확인해요.
렉이 심해요→ 6번 ②
"디스크 공간이 모자라요"나온 숫자만큼 그 드라이브의 공간을 비우고 다시 만들어요. 다 쓴 서버는 servers_old 폴더나 오래된 백업을 지우면 공간이 많이 생겨요.
서버 만들기나 업데이트가 실패했어요인터넷 연결을 확인하고 같은 이름으로 다시 해 보세요. 실패한 폴더는 자동으로 정리되고, 업데이트 실패 때는 서버가 예전 그대로예요.
"프로그램이 이미 열려 있어요"작업 표시줄에서 이미 열린 창을 찾아 주세요. 프로그램은 한 번에 하나만 열려요.
"문제가 생겼어요" 창이 떠요내용을 캡처해서 도와줄 사람에게 보내 주세요. 기록은 _program\logs\manager-errors.txt에 남아요.
