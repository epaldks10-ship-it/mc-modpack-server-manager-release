마인크래프트 모드팩 서버 사용 설명서

이 프로그램 하나로 모드팩 서버를 만들고, 켜고, 친구를 들여보내고, 모드를 추가할 수 있어요.

⚠ 꼭 먼저 읽어 주세요
  1. 이 폴더를 통째로 남에게 주거나 인터넷에 올리지 마세요.
    카톡, 디스코드, 구글 드라이브, 원드라이브 등에 모드팩서버관리.bat이 있는 폴더를 올리면 안 돼요. 안에 우리 월드, 화이트리스트, 서버 설정이 다 들어 있어요. (Playit 비밀 키는 이 PC에서만 풀리게 암호화돼 있어서 남이 쓸 수는 없어요)
    친구에게 보내도 되는 건 딱 두 가지예요. ① [친구 접속 안내]의 글, ② 친구용_추가모드 폴더.
  2. 서버가 켜져 있을 때 컴퓨터를 끄거나 프로그램을 강제 종료하지 마세요.
    반드시 [■ 서버 끄기]를 누르고 "꺼짐"이 될 때까지 기다리세요. 그냥 끄면 월드가 망가질 수 있어요.
  3. 같은 서버를 두 PC에서 동시에 켜지 마세요. 월드가 둘로 갈라져서 한쪽 플레이가 사라져요.
  4. 모드를 넣거나 빼기 전에는 [월드 백업]부터 하세요.

1. 처음 한 번만: Playit 연결 언제든지

Playit은 친구들이 들어올 인터넷 주소를 만들어 주는 무료 서비스예요. 공유기 설정은 필요 없어요. 처음 한 번만 하면 돼요. 혼자서만 할 거면 안 해도 돼요.

  1. 내 서버 탭 왼쪽의 Playit 연결 설정을 눌러요.
  2. 비밀 키 만드는 페이지 열기를 누르고 playit.gg에 로그인해요. 계정이 없으면 구글 계정 등으로 가입해요(무료).
  3. 화면 안내를 따라가면 비밀 키(Secret Key)가 나와요. 복사해요.
  4. 설정 창의 칸에 붙여 넣고 저장을 눌러요. 서버가 켜져 있었다면 Playit이 알아서 다시 켜져요. 키는 이 PC의 내 Windows 계정에서만 풀리게 암호화해서 저장해요.
  5. 터널 페이지 열기 → Add Tunnel을 눌러요. 종류 Minecraft Java, 주소 127.0.0.1, 포트 25565로 만들어요.
  6. 터널 목록의 어쩌구.joinmc.link 같은 주소가 우리 서버 주소예요. 친구들에게 알려 주세요. 이 주소는 바뀌지 않고, 어떤 모드팩 서버를 켜든 같은 주소를 써요.

설정이 끝나면 ▶ 친구랑 하기로 켤 때 Playit이 자동으로 같이 켜져요. 왼쪽 아래에 Playit: 실행 중이라고 나오면 정상이에요.

2. 서버 만들기 언제든지

다른 서버가 켜져 있어도 만들 수 있어요. 다만 만드는 동안에는 서버를 새로 켤 수 없어요.

  1. 새 서버 만들기 탭에서 왼쪽 목록의 모드팩을 눌러요.
  2. 버전을 골라요. 친구들도 꼭 같은 버전을 설치해야 해요. 테스트판이 붙은 버전은 피하세요.
  3. 서버 이름은 자동으로 채워져요. 바꾸려면 영어와 숫자로만 쓰세요.
  4. 서버 메모리는 권장값으로 채워져요. 이 컴퓨터에서 게임도 같이 하면 6GB 정도가 적당해요. 나중에 바꿀 수도 있어요(7번).
  5. 이용약관(EULA) 동의를 체크하고 서버 만들기를 눌러요.
  6. 검은 창이 뜨면서 설치가 진행돼요. 작은 팩은 몇 분, 큰 팩(ATM, Medieval MC)은 10~20분 걸려요. 이 검은 창은 닫지 마세요. 초록색으로 완료!가 나오면 Enter를 눌러 닫아요.

3. 서버 켜고 끄기

  1. 내 서버 탭 왼쪽 목록에서 서버를 골라요.
  2. 둘 중 하나를 눌러요. 검은 창 없이 이 프로그램 안에서 켜져요.
    • ▶ 친구랑 하기: 서버를 열고 Playit도 같이 켜요. 친구들은 Playit 주소로 들어와요.
    • ▶ 혼자 하기: 같은 월드를 내 컴퓨터에서만 열어요. 다른 사람은 못 들어와요. 친구랑 하던 월드를 혼자 이어서 할 때 쓰세요.
  3. 위쪽 막대와 글자로 진행 상황이 보여요. 초록색으로 "서버 열림!"이 나오면 들어갈 수 있어요. 소리도 한 번 나요.
  4. 마인크래프트를 켜고 멀티플레이 → 서버 추가에서 주소에 localhost를 넣고 들어가요. (서버를 켠 내 컴퓨터에서는 항상 localhost)
  5. 끌 때는 ■ 서버 끄기를 누르고 "꺼짐"이 될 때까지 기다려요. 월드를 저장하고 안전하게 꺼져요.
처음 켤 때는 화이트리스트가 비어 있어서 나도 못 들어가요. 친구 추가로 내 닉네임부터 추가하세요(4번).
  • 서버는 한 번에 하나만 켤 수 있어요. 다른 서버를 켜려면 지금 서버를 먼저 끄세요.
  • 서버가 켜진 채로 프로그램 창을 닫으려고 하면 "안전하게 끄고 닫을까요?"라고 물어봐요. 예를 누르면 저장하고 꺼진 뒤에 닫혀요.

명령어 보내기 서버 켜진 상태에서

아래쪽 칸에 명령어를 입력하고 Enter를 누르면 서버에 보낼 수 있어요. 앞에 /는 안 붙여도 돼요. 대부분은 버튼으로 할 수 있어서 몰라도 괜찮아요.

4. 친구 들여보내기

① 화이트리스트에 추가 (방장) 언제든지

서버는 허락한 사람만 들어올 수 있게 되어 있어요. 친구 추가를 누르고 친구의 마인크래프트 닉네임을 입력하세요. 나(방장)도 처음 한 번 추가해야 해요.

  • 서버가 켜져 있으면 바로 추가돼요.
  • 서버가 꺼져 있으면 기억해 뒀다가 다음에 서버가 열릴 때 자동으로 추가해요.

② 친구 PC 준비 (친구)

친구 접속 안내를 누르면 친구에게 보낼 안내문(메모장)이 열려요. 그대로 복사해서 보내 주세요. 내용은 이래요.

  1. CurseForge 앱(curseforge.com/download/app) 또는 Modrinth 앱(modrinth.com/app)을 설치해요.
  2. 안내문에 적힌 모드팩을 검색해서 같은 버전으로 설치해요.
  3. 앱 설정에서 메모리(램)를 6~8GB로 올려요. 모드가 많아서 기본값이면 게임이 멈춰요.
  4. 방장이 모드를 따로 추가했다면, 게임을 끈 상태에서 친구용_추가모드 폴더의 파일을 모드팩의 mods 폴더에 넣어요. (앱에서 모드팩 오른쪽 위 점 3개 → Open Folder → mods)
  5. 게임 실행 → 멀티플레이 → 서버 추가 → 방장이 알려 준 주소(어쩌구.joinmc.link)를 입력해요.

5. 모드 추가 / 빼기 서버 끈 상태에서

서버가 켜져 있으면 버튼이 눌리지 않아요. 먼저 ■ 서버 끄기를 하고, 월드 백업도 해 두세요.

  1. 모드 추가 / 관리를 눌러요.
  2. 검색 칸에 모드 이름(영어)을 입력하고 검색을 눌러요. 이 서버의 마인크래프트 버전과 로더에 맞는 모드만 나와요.
  3. 목록에서 모드를 고르고 선택한 모드 추가를 눌러요. 필요한 선행 모드도 자동으로 같이 받아요.
  4. 친구들도 넣어야 하는 파일은 친구용_추가모드 폴더에 모여요. 친구용 추가모드 폴더 열기로 열어서 압축한 뒤 친구들에게 보내 주세요. [친구 접속 안내]에도 자동으로 적혀요.
  5. 서버를 켜서 서버 열림!까지 가는지 확인해요.
검색 결과의 "종류"어디에 들어가나요
서버+친구서버와 친구 모두 넣어야 해요. 대부분의 모드예요.
서버 전용서버에만 들어가요. 친구들은 안 넣어도 돼요.
화면 전용미니맵, 셰이더 같은 모드예요. 서버에는 안 넣고 친구용 폴더에만 넣어요. 각자 원하면 넣는 모드예요.

Modrinth에 없는 모드는 내 컴퓨터의 .jar 파일 추가로 넣을 수 있어요. 이때는 마인크래프트 버전과 로더가 맞는지, 선행 모드가 필요한지 직접 확인해야 해요.

  • 한 번에 하나씩 넣고 켜 보세요. 여러 개를 한꺼번에 넣으면 뭐가 문제인지 모르게 돼요.
  • 쓰던 모드를 빼면 그 모드의 아이템과 블록이 월드에서 사라져요.
  • 새 모드의 광석이나 구조물은 아직 안 가 본 지역에만 생겨요.

6. 모드팩 업데이트 서버 끈 상태에서

서버를 고르면 새 버전이 있는지 자동으로 확인해요. 새 버전이 있으면 왼쪽의 버튼이 노란색 "모드팩 업데이트: 새 버전 있음!"으로 바뀌어요.

  1. 서버를 끄고 노란 버튼을 눌러요.
  2. 안내를 읽고 예를 누르면 검은 창에서 업데이트가 진행돼요. 이 창은 닫지 마세요.
  3. 끝나면 친구들에게도 모드팩을 같은 새 버전으로 업데이트하라고 알려 주세요.
월드, 화이트리스트, 관리자 목록, 서버 설정, 직접 추가한 모드는 그대로 옮겨요. 시작하기 전에 월드를 자동으로 백업하고, 예전 서버는 servers_old 폴더에 그대로 보관해요. 중간에 실패하면 서버는 예전 버전 그대로 남아요.

마인크래프트 버전 자체가 바뀌는 업데이트(예: 1.20.1 → 1.21.1)는 월드가 망가질 수 있어서 버튼에 나오지 않아요. 그럴 땐 새 서버로 만드세요.

7. 서버 램(메모리) 바꾸기 서버 끈 상태에서

  1. 서버를 꺼요.
  2. 내 서버 탭 오른쪽 위 서버 램(GB) 칸의 숫자를 바꾸고 램 바꾸기를 눌러요.
  3. 다음에 서버를 켤 때부터 적용돼요.

렉이 심하거나 OutOfMemoryError가 나면 1~2GB씩 올려 보세요. 같은 PC에서 게임도 하면 컴퓨터 전체 램의 절반을 넘기지 않는 게 좋아요(게임에도 6~8GB가 필요해요).

8. 백업, 다른 PC로 옮기기

월드 백업 서버 끈 상태에서

월드 백업을 누르면 서버 폴더의 backups에 날짜 이름으로 저장돼요. 일주일에 한 번, 그리고 모드를 바꾸기 전에는 꼭 해 주세요.

백업에서 되돌리기 서버 끈 상태에서

  1. 서버를 꺼요. 서버 폴더 열기를 눌러요.
  2. world 폴더 이름을 world_old로 바꿔요.
  3. backups 폴더의 zip을 오른쪽 클릭 → 압축 풀기해서 나온 world 폴더를 서버 폴더에 넣어요.
  4. 서버를 켜서 확인해요. 잘 되면 world_old는 지워도 돼요.

다른 PC로 옮기기 서버 끄고 프로그램도 닫은 상태에서

  1. 서버를 끄고 이 프로그램을 닫아요.
  2. 모드팩서버관리.bat이 들어 있는 폴더 전체를 USB나 외장하드로 새 PC에 복사해요. (인터넷에 올려서 옮기지 마세요. 맨 위 주의사항 1번)
  3. 새 PC에서 모드팩서버관리.bat을 실행해요. Java 설치는 다시 할 필요 없어요.
  4. Playit 키는 예전 PC에서만 풀리게 암호화돼 있어서, 새 PC에서는 Playit 연결 설정에서 키를 한 번 다시 넣어야 해요. (playit.gg에서 키를 새로 만들어도 돼요)
  • 64비트 Windows에서만 돼요.
  • 옮긴 다음에는 예전 PC에서 켜지 마세요. 항상 마지막에 플레이한 폴더 하나만 쓰세요.

9. 보안 언제든지

서버를 켤 때마다 안전한 설정(정품 인증, 화이트리스트, 원격 관리 끄기, 내 PC 안에서만 접속 받기)을 자동으로 맞춰요. 따로 할 일은 없어요. 보안 점검을 누르면 상태와 디도스(DDoS) 대처법을 볼 수 있어요.

  • Playit 비밀 키는 이 PC에서만 풀리게 암호화해서 저장해요.
  • 프로그램은 켤 때 새 버전이 있으면 자동으로 업데이트해요. 업데이트 파일은 개발자의 디지털 서명이 맞을 때만 설치해서, 가짜 업데이트는 설치되지 않아요.
  • 친구들에게는 Playit 주소만 알려 주세요. 우리 집 IP 주소는 알려 주지 마세요.
  • 공유기 포트포워딩은 하지 마세요. Playit을 쓰면 필요 없고, 하면 집 IP가 드러나요.
  • 공격을 받는 것 같으면(갑자기 렉, 접속 끊김) playit.gg에서 터널을 지우고 새로 만드세요. 주소가 바뀌어서 공격이 끊겨요.
  • 처음 서버를 켤 때 Windows 방화벽 허용 창이 뜨면 [취소]를 눌러도 돼요. Playit은 방화벽을 열지 않아도 동작해요.
  • 모드는 Modrinth, CurseForge 공식 사이트에서만 받으세요. 출처 모를 .jar 파일에는 악성코드가 있을 수 있어요.

10. 문제 해결

이런 일이 생기면이렇게 하세요
로그에 빨간 글씨나 ERROR가 많아요모드가 많으면 원래 그래요. "서버 열림!"까지 가면 정상이에요.
"켜지다가 멈췄어요"가 떠요원인 모드를 찾으면 "이 모드를 빼고 다시 켤까요?"라고 물어봐요. 보통 화면 전용 모드 때문이라 예를 누르면 돼요.
"다른 서버가 이미 켜져 있어요"서버는 한 번에 하나만 켤 수 있어요. 켜져 있는 서버를 먼저 끄세요. 예전에 서버켜기.bat(검은 창)으로 켠 서버가 있다면 그 창에 stop을 입력해서 끄세요.
나도 못 들어가요친구 추가로 내 닉네임을 추가했는지 확인해요. 주소는 localhost예요.
친구가 접속을 못 해요① 상태가 "서버 열림!"인지 ② ▶ 친구랑 하기로 켰는지(혼자 하기 X) ③ 왼쪽 아래가 "Playit: 실행 중"인지 ④ 친구가 주소를 맞게 넣었는지 ⑤ 화이트리스트에 추가했는지 확인해요.
"You are not white-listed"친구 추가로 그 사람의 닉네임을 추가해요.
"Mod rejections", "mismatched mods"친구의 모드팩 버전이나 추가 모드가 서버와 달라요. 같은 버전인지, 친구용_추가모드를 다 넣었는지 확인해요.
렉이 심하거나 OutOfMemoryError7번처럼 서버를 끄고 램을 올려요.
서버 만들기나 업데이트가 실패했어요인터넷 연결을 확인하고 다시 해 보세요. 실패한 폴더는 자동으로 지워지고, 업데이트 실패 때는 서버가 예전 그대로예요. 기록은 _program\logs에 남아요.
서버 설정(난이도, 최대 인원 등)을 바꾸고 싶어요서버를 끈 상태에서 서버 폴더의 server.properties를 메모장으로 열어 고치고 저장해요. 켜져 있을 때 고치면 꺼질 때 원래대로 돌아갈 수 있어요.
그래도 모르겠어요서버 폴더의 logs\latest.log나 crash-reports 폴더의 최신 파일을 도와줄 사람에게 보여 주세요.
