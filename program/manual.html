마인크래프트 모드팩 서버 사용 설명서

이 프로그램 하나로 서버를 만들고, 켜고, 친구를 들여보내고, 모드와 설정을 바꿀 수 있어요. 파일을 직접 열어서 고칠 일은 없어요.

⚠ 꼭 먼저 읽어 주세요
  1. 이 폴더를 통째로 남에게 주거나 인터넷에 올리지 마세요.
    카톡, 디스코드, 구글 드라이브, 원드라이브 등에 모드팩서버관리.exe가 있는 폴더를 올리면 안 돼요. 우리 월드, 화이트리스트, 서버 설정이 다 들어 있어요.
    친구에게 보내는 건 초대 링크(또는 [친구 접속 안내]의 글) 하나뿐이에요. 모드팩이나 모드 파일은 보내지 않아요. 남이 만든 파일을 직접 건네면 재배포라 문제가 될 수 있어서, 친구는 언제나 공식 사이트에서 받아요. → 4번
  2. 서버가 켜져 있을 때 컴퓨터를 끄지 마세요.
    반드시 ■ 서버 끄기를 누르고 "꺼짐"이 될 때까지 기다리세요. 그냥 끄면 월드가 망가질 수 있어요. (프로그램 창을 닫으려고 하면 "안전하게 끄고 닫을까요?"라고 물어봐 줘요)
  3. 같은 서버를 두 PC에서 동시에 켜지 마세요. 월드가 둘로 갈라져서 한쪽 플레이가 사라져요.
  4. 모드를 넣거나 빼기 전에는 백업부터 하세요. → 7번 ①
처음 시작하기: 이 순서대로만 하면 돼요
  1. 모드팩서버관리.exe를 더블클릭해서 프로그램을 켜요.
  2. 친구랑 할 거라면 Playit부터 연결해요. → 1번 (혼자만 할 거면 건너뛰어요)
  3. 모드팩을 골라 서버를 만들어요. → 2번
  4. 서버를 켜요. → 3번
  5. ▶ 마인크래프트 켜기를 눌러요. 모드팩 게임이 자동으로 준비되고 런처가 열려요. (처음 한 번 내 닉네임을 물어봐요) → 3번 ④
  6. 친구 닉네임을 추가하고, 친구 초대 링크 복사로 링크를 보내요. → 4번 ①, ②
막히면 → 10번 문제 해결에서 증상을 찾아보세요.
제목 옆 표시 서버 끈 상태에서 서버가 켜져 있으면 버튼이 막혀요 서버 켜진 상태에서 언제든지

1. Playit 연결 (처음 한 번만) 언제든지

Playit은 친구들이 들어올 인터넷 주소를 만들어 주는 무료 서비스예요. 공유기 설정은 필요 없어요.

  1. 내 서버 탭 왼쪽의 Playit 연결 설정을 눌러요. 창에 ①~⑤ 순서가 적혀 있어요. playit.gg 사이트는 영어라서, 누를 버튼과 칸 이름을 영어 그대로 적었어요.
  2. [가입·로그인] playit.gg 열기 → 계정이 없으면 Create a new account로 가입해요(이메일, 비밀번호, 무료). 받은 메일의 인증 링크까지 누르면 끝이에요. 계정이 있으면 로그인만 해요.
  3. [비밀 키 받기] 비밀 키 만드는 페이지 열기를 눌러요. "Where do you want to integrate Playit?" 화면이 나오면 Docker를 골라요. (내 PC에 Playit을 따로 설치하는 게 아니라, 이 프로그램 안의 Playit이 대신 연결돼서 Docker를 골라요)
  4. Agent Name 칸에 영어 이름(예: mcserver)을 넣고 Create Agent를 눌러요. "Start the Docker container" 화면이 나오면 Docker run 옆의 Copy를 눌러요. 그 명령어 줄 안에 비밀 키(SECRET_KEY)가 들어 있어요.
  5. 설정 창의 칸에 그대로 붙여 넣고 저장을 눌러요. 프로그램이 키만 골라내고, 바로 Playit을 연결해요. 사이트의 Agents 메뉴에서 그 이름 옆에 connected가 보이면 성공이에요. 키는 이 PC의 내 Windows 계정에서만 풀리게 암호화돼서 저장돼요. (Docker 화면 아래 버튼이 계속 Loading...이어도 괜찮아요. 그냥 다음으로 가요)
  6. [터널 만들기] 터널 페이지 열기 → Create Tunnel(터널이 하나도 없으면 Create your first tunnel)을 눌러요. 칸이 하나씩 열리는데, 하나 고를 때마다 Next를 눌러요.
    칸 이름넣을 것
    Name your tunnel아무 이름 (예: minecraft)
    Tunnel TypeMinecraft Java
    Public EndpointFree Network (Premium Network는 돈이 들어요)
    Assign to Agent앞에서 넣은 이름 (예: mcserver). "tunnel type not supported"라고 나오면 키를 저장하고 Playit이 한 번 연결된 다음 다시 해요.
    Origin ConfigLocal IP 127.0.0.1, Local Port 25565 (처음부터 들어 있어요. Proxy Protocol은 None 그대로)
    맨 아래 Create Tunnel을 누르면 잠깐 "Allocating address..."가 나왔다가 주소가 생겨요.
  7. 터널 화면 맨 위의 어쩌구.tun.ply.gg 같은 주소가 우리 서버 주소예요. 프로그램이 1분 안에 Playit에 물어봐서 설정 창 칸에 알아서 넣어요. 자동으로 가져오기를 누르면 바로 받아요. (안 되면 주소를 복사해서 붙여 넣고 저장)
    프로그램을 켤 때와 친구 접속 안내를 열 때도 다시 확인하니까, 터널을 새로 만들어 주소가 바뀌어도 알아서 따라가요.
  8. 이제 왼쪽 아래 친구에게 줄 주소 복사로 언제든 주소를 복사할 수 있고, 친구 접속 안내에도 주소가 자동으로 들어가요. → 다음: 4번 ②에서 친구에게 보내요

이제 ▶ 친구랑 하기로 켜면 Playit도 같이 켜지고, 서버를 끄면 같이 꺼져요. 왼쪽 아래에 Playit: 실행 중이 보이면 정상이에요. 어떤 모드팩 서버를 켜든 같은 주소를 써요. ▶ 친구랑 하기로 켜 둔 채로 키를 저장해도 서버를 끄지 않고 바로 연결돼요.

2. 서버 만들기 언제든지

  1. 새 서버 만들기 탭에서 왼쪽 목록의 모드팩을 눌러요. (어떤 걸 고를지 모르겠으면 아래 표의 Better MC)
  2. 버전을 골라요. 친구들도 꼭 같은 버전을 설치해야 해요. 테스트판이 붙은 버전은 피하세요.
  3. 서버 이름은 자동으로 채워져요. 바꾸려면 영어와 숫자로만 쓰세요.
  4. 서버 메모리는 권장값으로 채워져요. 이 컴퓨터에서 게임도 같이 하면 6GB 정도가 적당해요. 나중에 바꿀 수 있어요. → 6번 ③
  5. 이용약관(EULA) 동의를 체크하고 서버 만들기를 눌러요.
  6. 아래 칸에 진행 상황이 나와요. 작은 팩은 몇 분, 큰 팩(ATM, Medieval MC)은 10~20분 걸려요. "완료!"가 나오면 자동으로 내 서버 탭으로 넘어가요. → 다음: 3번

만드는 동안 프로그램을 닫으면 중단돼요. 그래도 괜찮아요. 다음에 프로그램을 켜면 끝나지 못한 폴더를 알아서 정리하니까, 같은 이름으로 다시 만들면 돼요.

목록에 없는 모드팩 넣기

  1. 목록 아래 + 모드팩 추가를 눌러요.
  2. Modrinth 모드팩: 모드팩 페이지의 주소(예: https://modrinth.com/modpack/...)를 그대로 붙여 넣어요.
  3. CurseForge 모드팩: 모드팩 페이지의 주소(예: https://www.curseforge.com/minecraft/modpacks/...)를 그대로 붙여 넣거나, 페이지 오른쪽 About Project 칸의 Project ID 숫자를 넣어요.
    CurseForge는 모드팩 만든 사람이 서버팩을 올려 둔 경우에만 넣을 수 있어요. 새 버전은 하루에 한 번, 목록에서 고를 때 확인해요.
  4. 목록에 ★ 표시로 생겨요. 그다음은 위의 2~6번과 똑같아요. 친구 접속 코드에도 모드팩 정보가 같이 들어가서, 친구도 그대로 들어올 수 있어요.
  5. 필요 없어지면 고르고 목록에서 빼기. (이미 만든 서버는 그대로 있어요)

3. 서버 켜고 끄기

  1. 내 서버 탭 왼쪽 목록에서 서버를 골라요.
  2. 둘 중 하나를 눌러요.
    • ▶ 친구랑 하기: 서버를 열고 Playit도 같이 켜요. 친구들은 Playit 주소로 들어와요. (Playit 연결이 아직이면 → 1번)
    • ▶ 혼자 하기: 같은 월드를 내 컴퓨터에서만 열어요. 다른 사람은 못 들어와요. 친구랑 하던 월드를 혼자 이어서 할 때 쓰세요.
  3. 위쪽 막대와 글자로 진행 상황과 남은 시간이 보여요. 초록색으로 "서버 열림!"이 나오면 다 켜진 거예요. 소리도 한 번 나요.
  4. [게임 켜기] 왼쪽 ▶ 마인크래프트 켜기를 눌러요. CurseForge 앱은 필요 없어요.
    • 서버와 똑같은 모드팩 게임을 준비해요. 처음엔 몇 분 걸리고, 다음부터는 바로 넘어가요. 모드팩을 업데이트하거나 모드를 넣으면 게임도 알아서 맞춰요.
    • 공식 마인크래프트 런처가 열려요. [플레이] 옆 설치 목록에서 모드팩: ...을 고르고 플레이.
    • 게임이 켜지면 멀티플레이 → 맨 위 서버이름 (내 서버) → 서버 접속. 주소는 이미 들어 있어요.
    • 로그인은 런처에서 내 마이크로소프트 계정으로 해요. 이 프로그램은 비밀번호를 다루지 않아요.
    • 런처가 없으면 다운로드 페이지를 열어 줘요. 설치하고 한 번 로그인한 다음 다시 누르세요.
  5. 끌 때는 ■ 서버 끄기를 누르고 "꺼짐"이 될 때까지 기다려요.

4. 친구 들여보내기

① 화이트리스트에 추가 언제든지

  1. 친구 추가를 눌러요.
  2. 닉네임(마인크래프트 자바 계정 이름)을 입력하고 확인을 눌러요. 처음엔 내 닉네임부터 넣으세요.
  3. 서버가 켜져 있으면 바로 추가되고, 꺼져 있으면 다음에 서버가 열릴 때 자동으로 추가돼요.
  4. 깜빡하고 안 넣었어도 괜찮아요. 친구가 들어오려다 막히면 프로그램이 "지금 추가할까요?"라고 물어봐요. 아는 친구일 때만 예를 누르세요. (아니요를 누른 이름은 서버를 다시 켤 때까지 또 묻지 않아요)

② 친구에게 초대 링크 보내기 언제든지

  1. 왼쪽 친구 초대 링크 복사를 눌러요.
  2. 카톡이나 디스코드에 붙여 넣어요. 짧은 링크 한 줄이에요. 서버 주소, 모드팩, 모드 목록은 링크 안에 압축하고 암호화해서 넣어 두기 때문에, 대화방에서 다른 사람이 봐도 무슨 내용인지 알 수 없어요.
  3. 모드를 추가하거나 빼면 링크도 바뀌어요. 다시 눌러서 새 링크를 보내 주세요. 친구는 새 링크만 열면 바뀐 모드까지 알아서 맞춰요.
  4. 내 컴퓨터의 .jar 파일 추가로 넣은 모드 중 Modrinth에 없는 것은, 프로그램이 그 모드를 받은 공식 페이지 주소를 물어봐요(CurseForge, GitHub 등). 친구에게는 파일 대신 그 링크와 넣는 방법을 알려 줘요. 나중에 넣으려면 모드 추가 / 관리 → 목록에서 고르고 → 선택한 모드의 원본 주소 넣기.
링크는 믿는 친구에게만 보내세요. 링크의 암호화는 대화방을 훔쳐보는 사람에게서 내용을 가리는 것이지 비밀번호는 아니에요. 진짜로 막아 주는 건 화이트리스트예요. (링크를 열어도 화이트리스트에 없으면 못 들어와요)

예전처럼 긴 안내 글이 필요하면 친구 접속 안내 → 글 전체 복사를 써도 돼요. 안내 글 안에도 같은 초대 링크와 코드가 들어 있어요.

③ 친구가 할 일: 제일 쉬운 방법 (초대 링크)

  1. PC에서 받은 링크를 열어요. (휴대폰으로 받았으면 링크를 PC로 보내서 열어요)
  2. 페이지의 모드팩서버관리 프로그램 받기를 눌러요. 초대 코드도 같이 복사돼요. 받은 파일의 압축을 풀고 모드팩서버관리.exe를 켜요.
    (이미 프로그램이 있으면 초대 코드만 다시 복사를 누르고 프로그램을 켜요)
  3. 프로그램이 복사해 둔 코드를 찾아서 친구 서버 들어가기 탭에 넣어 줘요. ▶ 설치하고 게임 켜기를 눌러요. (코드가 안 들어가 있으면 링크를 통째로 칸에 붙여 넣어도 돼요)
  4. 같은 모드팩, 같은 버전, 방장이 추가한 Modrinth 모드까지 공식 사이트에서 알아서 받아요. (CurseForge 모드팩은 CurseForge가 올려 둔 공식 서버팩을 받고, 화면에 필요한 모드를 Modrinth에서 채워 넣어요. CurseForge 앱은 필요 없어요) 런처가 열리면 모드팩: ... → 플레이 → 멀티플레이 → 서버 접속.
  5. 방장이 원본 링크로 알려 준 모드가 있으면, 설치가 끝난 다음 추가 모드 직접 받기 창이 떠요. 선택한 모드 페이지 열기 → 같은 마인크래프트 버전의 파일을 받아서 → 넣을 폴더 열기로 열린 직접_받은_모드 폴더에 넣어요. 게임을 켤 때마다 알아서 넣어 주고, 다시 설치해도 안 지워져요.
  6. 다음부터는 같은 탭의 설치해 둔 친구 서버에서 ▶ 게임 켜기만 누르면 돼요. 방장이 모드나 모드팩을 바꿨다면 새 링크를 다시 열어요.
  7. 게임이 빨간 Error loading mods 화면에서 멈추면, 게임을 닫고 ▶ 게임 켜기를 한 번 더 눌러요. 프로그램이 오류 보고서를 읽고 고쳐요(맞는 버전 다시 받기, 서버 접속에 필요 없는 화면용 모드는 빼기). 뺀 모드는 게임 폴더의 _disabled_mods에 있어요.
  8. 셰이더: 모드팩에 셰이더 모드(Oculus 등)가 들어 있으면, 게임 안 옵션 → 비디오 설정 → 셰이더 팩...에서 셰이더를 고르고 적용을 눌러요. (키보드 O로도 열려요. 컴퓨터가 버벅이면 꺼짐으로)

방장이 중간에 모드를 바꾸면

  • 방장: 서버를 끄고 모드를 바꾼 다음 다시 켜면, 콘솔에 "모드가 달라졌어요"가 떠요. 앱으로 하는 친구와 처음 오는 친구에게만 친구 초대 링크 복사로 새 링크를 보내면 돼요.
  • 프로그램을 쓰는 친구: 설치해 둔 친구 서버에서 ▶ 게임 켜기만 누르면, 프로그램이 방장 서버에 바뀐 게 있는지 물어보고 알아서 맞춰요. Modrinth 모드는 새로 받고 뺀 건 지워요. 새 [링크] 모드가 있으면 받는 창이 떠요. 예전에 CurseForge 앱으로 깔았던 서버도 이때 프로그램이 알아서 다시 준비해요. (방장 서버가 켜져 있어야 확인할 수 있어요)
  • 앱으로 하는 친구: 방장이 보낸 새 링크를 전에 열었던 브라우저로 열면, 맨 위에 지난번과 달라진 점이 나와요. 새로 넣을 모드는 링크로 받고, 빠진 모드는 mods 폴더에서 지우고, 모드팩 버전이 바뀌었으면 앱에서 업데이트해요.

④ 친구가 할 일: 앱으로 직접 하는 방법

  1. CurseForge 앱 또는 Modrinth 앱을 설치해요.
  2. 초대 링크 페이지 맨 아래 프로그램 없이 직접 하기 버튼을 누르면 앱 받는 곳, 모드팩 이름과 버전, 공식 페이지, 추가 모드마다의 공식 링크, 주소가 순서대로 나와요. (이 화면 주소만 따로 보내도 돼요. [친구 접속 안내] 글에도 들어 있어요) 그 모드팩을 검색해서 같은 버전으로 설치해요. (Mac도 이 방법으로 해요)
  3. 앱 설정에서 메모리(램)를 6~8GB로 올려요.
  4. 추가 모드가 있으면 페이지에 나온 모드마다의 공식 링크에서 같은 마인크래프트 버전의 파일을 받아서, 게임을 끈 상태에서 모드팩의 mods 폴더에 넣어요. (앱에서 모드팩 오른쪽 위 점 3개 → Open Folder → mods)
  5. 게임 실행 → 멀티플레이 → 서버 추가 → 받은 Playit 주소 입력 → 접속.

5. 모드 추가 / 빼기 서버 끈 상태에서

  1. 서버를 끄고 백업해요. → 7번 ①
  2. 모드 추가 / 관리를 눌러요.
  3. 검색 칸에 모드 이름(영어)을 넣고 검색. 이 서버에 맞는 모드만 나와요.
  4. 모드를 고르고 선택한 모드 추가. 필요한 선행 모드도 자동으로 같이 받아요.
  5. 서버를 켜서 "서버 열림!"까지 가는지 확인해요. → 3번 (안 켜지면 → 10번)
  6. 초대 링크 복사로 친구들에게 새 링크를 보내요. 친구는 링크만 열면 새 모드까지 자동으로 받아요. → 4번 ②

"이 서버에 직접 추가한 모드" 목록의 표시는 이런 뜻이에요.

  • [자동] Modrinth 모드라서 친구 PC가 Modrinth에서 알아서 받아요. 내 컴퓨터의 .jar 파일 추가로 넣은 파일도 Modrinth에 있는 파일이면 알아서 찾아서 [자동]이 돼요.
  • [링크] Modrinth에 없어서, 친구가 내가 적어 둔 공식 페이지에서 직접 받아요.
  • [주소 필요] 받는 곳이 없어요. 목록에서 고르고 선택한 모드의 원본 주소 넣기를 눌러 주세요. 파일을 직접 보내는 건 재배포라 하지 않아요.
검색 결과의 "종류"어디에 들어가나요
서버+친구서버와 친구 모두 넣어야 해요. 대부분의 모드예요.
서버 전용서버에만 들어가요. 친구들은 안 넣어도 돼요.
화면 전용미니맵, 셰이더 같은 모드예요. 서버에는 안 넣고 친구용 폴더에만 넣어요.
  • Modrinth에 없는 모드는 내 컴퓨터의 .jar 파일 추가로 넣을 수 있어요. 마인크래프트 버전과 로더가 맞는지는 직접 확인해야 해요.
  • 한 번에 하나씩 넣고 켜 보세요.
  • 쓰던 모드를 빼면 그 모드의 아이템과 블록이 월드에서 사라져요.

6. 서버 설정 바꾸기 서버 끈 상태에서

① 난이도, 게임 모드, 최대 인원 등

  1. 서버를 꺼요.
  2. 서버 설정 (난이도, 인원 등)을 눌러요.
  3. 바꾸고 싶은 항목을 고르고 저장. 다음에 켤 때부터 적용돼요. (서버가 켜져 있으면 볼 수만 있고 저장은 막혀 있어요)

새로 만든 서버는 처음부터 모드팩에 맞는 값으로 시작해요. 마인크래프트 기본값은 모드 없는 서바이벌에 맞춰져 있어서 모드팩에서는 문제가 생기거든요.

설정마인크래프트 기본이 프로그램왜
비행 허용끔켬제트팩, 날개, 날아다니는 탈것을 쓰면 "Flying is not enabled"로 쫓겨나요.
스폰 보호 범위16블록64블록 (최대)스폰 근처는 방장(관리자)만 고칠 수 있어서, 장난이나 실수로 망가지지 않아요. 친구들은 스폰에서 조금 떨어진 곳에 집을 지으면 돼요.
난이도쉬움보통 (좀비 모드팩은 어려움)모드팩 몬스터와 보상이 보통 이상에 맞춰져 있어요.
시야 / 움직이는 거리10 / 108 / 6 (Cobblemon은 10 / 8)모드가 많으면 서버가 버거워해요.
멈춤 감지 시간60초180초첫 월드를 만들 때 오래 걸려도 서버가 멈춘 걸로 보고 꺼 버리지 않아요.

이미 만들어 둔 서버는 이 모드팩에 맞는 추천값 넣기 → 저장을 누르면 같은 값이 들어가요. 모드팩 업데이트는 내가 바꾼 설정을 그대로 가져가요.

② 렉이 심할 때 / 여럿이 할 때

①의 창에서 시야 거리와 움직이는 거리를 6~8로 낮춰 보세요. 그래도 심하면 ③으로 가요.

10명 넘게 같이 할 거라면 ①의 창 아래 여럿이 할 때 추천값 넣기를 누르세요. 최대 인원 25명, 시야 거리 8, 움직이는 거리 6이 들어가고, 이 모드팩과 이 PC에 맞는 서버 램도 알려 줘요. 저장을 눌러야 적용돼요.

서버가 켜져 있는 동안 렉이 계속 생기면(로그의 "Can't keep up!") 프로그램이 위쪽 글로 알려 줘요.

③ 서버 램(메모리) 바꾸기

  1. 서버를 꺼요.
  2. 오른쪽 위 서버 램(GB) 칸의 숫자를 바꾸고 램 바꾸기.
  3. 다음에 켤 때부터 적용돼요.

같은 PC에서 게임도 하면 컴퓨터 전체 램의 절반을 넘기지 않는 게 좋아요(게임에도 6~8GB가 필요해요).

램이 빠듯한 PC에서 ▶ 마인크래프트 켜기를 누르면 서버 램을 4GB로 줄일지 물어봐요. 혼자나 2~3명이 할 때만 물어보고, 친구가 많은 서버(지금 3명 이상 접속해 있거나 화이트리스트에 6명 이상 있을 때)는 줄이지 않아요. 여럿이 놀 때 서버 램을 줄이면 서버가 꺼질 수 있어서예요.

서버를 켤 때마다 서버용 메모리 정리 설정(GC 옵션)도 알아서 넣어요. 메모리 정리 때문에 몇 초씩 멈추는 일이 줄어서, 여럿이 할 때 렉이 덜해요. 모드팩이 자기 설정을 넣어 둔 경우에는 그대로 둬요.

④ 모드팩 업데이트

새 버전이 나오면 왼쪽 버튼이 노란색 "모드팩 업데이트: 새 버전 있음!"으로 바뀌어요.

  1. 서버를 끄고 노란 버튼을 눌러요.
  2. 안내를 읽고 예. 진행 상황은 아래쪽 로그 칸에 나와요.
  3. 끝나면 친구들에게 모드팩을 같은 새 버전으로 업데이트하라고 알려 주세요. → 4번 ②
월드, 화이트리스트, 설정, 직접 추가한 모드는 그대로 옮겨요. 시작 전에 월드를 자동으로 백업하고, 예전 서버는 servers_old에 보관해요. 중간에 끊기면 다음에 프로그램을 켤 때 원래대로 되돌려요.

7. 백업과 월드 관리 서버 끈 상태에서

백업 / 월드 관리를 누르면 아래 기능이 다 있어요.

① 지금 백업하기

서버를 끌 때마다 자동으로 백업해요 (auto_로 시작하는 것, 최근 5개만 남겨요). 끈 다음 상태가 잠깐 "자동 백업 중"이 됐다가 "꺼짐"으로 바뀌어요.

서버를 켜 둔 동안에도 3시간마다 자동으로 백업해요 (live_로 시작하는 것, 최근 8개만 남겨요). 그동안 아무도 안 들어왔으면 건너뛰어요. 백업하는 몇 초~몇 분 동안 잠깐 렉이 있을 수 있어요.

모드나 설정을 바꾸기 전에는 지금 백업하기도 한 번 눌러 두세요. 직접 만든 백업은 자동으로 지워지지 않아요. 지금 백업하기는 서버가 켜져 있어도 돼요(켜진 채로 백업해요).

② 예전으로 되돌리기

  1. 목록에서 돌아가고 싶은 때의 백업을 골라요.
  2. 선택한 백업으로 되돌리기 → 예. 지금 월드도 되돌리기 전에 자동으로 백업돼서, 마음이 바뀌면 그걸로 다시 되돌리면 돼요.

③ 월드 새로 만들기

월드 새로 만들기 (처음부터) → 시드는 모르면 비워 두고 확인. 지금 월드는 자동 백업돼요. 다음에 서버를 켤 때 새 월드가 만들어져요.

8. 다른 PC로 옮기기 서버 끄고 프로그램도 닫은 상태에서

  1. 서버를 끄고 프로그램을 닫아요.
  2. 모드팩서버관리.exe가 있는 폴더 전체를 USB나 외장하드로 새 PC에 복사해요. (인터넷으로 옮기지 마세요. 맨 위 주의사항 1)
  3. 새 PC에서 모드팩서버관리.exe를 실행해요.
  4. Playit 키는 예전 PC에서만 풀려서, 왼쪽 아래에 "키를 다시 넣어 주세요"가 나와요. → 1번 ①~④만 다시 하면 돼요 (터널과 주소는 그대로예요)
  5. 옮긴 다음에는 예전 PC에서 켜지 마세요.

9. 보안 언제든지

서버를 켤 때마다 안전한 설정(정품 인증, 화이트리스트, 원격 관리 끄기, 내 PC 안에서만 접속 받기)을 자동으로 맞춰요. 따로 할 일은 없어요. 상태는 보안 점검에서 볼 수 있어요.

  • 친구들에게는 Playit 주소만 알려 주세요. 우리 집 IP 주소는 알려 주지 마세요.
  • 공유기 포트포워딩은 하지 마세요. 필요 없고, 하면 집 IP가 드러나요.
  • 처음 서버를 켤 때 Windows 방화벽 창이 뜨면 [취소]를 눌러도 돼요.
  • 모드는 Modrinth, CurseForge 공식 사이트에서만 받으세요.
  • 프로그램은 켤 때 새 버전이 있으면 자동으로 업데이트해요. 개발자의 디지털 서명이 맞는 파일만 설치해요.

프로그램이 알아서 막는 것

  • 화이트리스트에 없는 사람이 계속 들어오려고 하면(10분 동안 모르는 이름 6개, 또는 1분에 20번) 공격 의심으로 알려 줘요. 그때부터는 "지금 추가할까요?"를 묻지 않아요. 실수로 모르는 사람을 들여보내는 일이 없게요. (아는 친구는 친구 추가로 직접 넣으면 돼요)
  • 1분에 60번 넘게 몰려오면 Playit 연결을 10분 동안 끊어요. 서버와 월드는 그대로 켜져 있고, 10분 뒤 알아서 다시 연결해요. 왼쪽 아래에 "공격 의심으로 쉬는 중"이 보여요.
  • 친구 닉네임으로 들어오려다 정품 확인에 실패한 것도 공격으로 세요. 정품 인증 덕분에 남의 이름으로는 들어올 수 없어요.
  • 기록은 서버 폴더의 security-log.txt에 남고, 보안 점검에 최근 24시간 동안의 횟수가 보여요.
  • 모드 악성코드 검사: 서버를 켤 때, 게임을 켤 때, 내 컴퓨터의 .jar 파일 추가로 모드를 넣을 때 모드 파일에 악성코드(2023년에 퍼진 fractureiser)가 없는지 확인해요. 걸리면 켜지 않고, 그 파일을 격리된_위험한_모드 폴더로 옮길지 물어봐요. 처음 한 번은 모드가 많으면 1~2분 걸리고, 그다음부터는 새 파일만 확인해서 금방이에요. 프로그램을 켤 때는 이 PC가 이미 감염됐는지도 확인해요.
  • 관리자(OP)는 방장만: 서버를 켤 때마다 방장을 관리자로 정해요. 관리자가 있어야 스폰 보호가 작동하거든요. 콘솔에 op 이름으로 다른 사람을 관리자로 만들려고 하면 한 번 더 물어봐요.

보안 점검에서 같이 보는 것

  • 오래 안 들어온 친구: 30일 넘게 안 온 친구가 보여요. 친구 계정이 털리면 그 계정으로 들어올 수 있으니, 고칠 수 있는 것 자동으로 고치기로 화이트리스트에서 빼 두세요. (빼기 전에 이름을 보여 주고 물어봐요. 다시 오면 친구 추가로 넣으면 돼요)
  • 백업을 PC 밖에도 복사: 디스크가 고장 나거나 랜섬웨어에 걸리면 월드와 백업이 같이 사라져요. 백업 / 월드 관리 → 복사할 곳 고르기에서 OneDrive 폴더나 USB를 고르면, 새 백업이 생길 때마다 그곳에도 복사해요(최근 10개).
  • 내 계정 지키기 (직접 해 주세요): 마이크로소프트 계정과 playit.gg 계정에 2단계 인증을 켜 두세요. Playit 계정이 털리면 남이 터널을 가져갈 수 있어요.

공격(디도스)을 받는 것 같을 때 (갑자기 렉, 다들 접속이 끊김, 모르는 이름이 계속 보임)

제일 확실한 방법은 주소를 바꾸는 것이에요. 서버는 켜 둔 채로 해도 돼요.

  1. 보안 점검 → 주소 바꾸기 도우미를 눌러요. (공격 의심 알림 창에서 예를 눌러도 열려요)
  2. 터널 페이지 열기 → 지금 쓰던 터널을 지우고(Delete), Create Tunnel → Minecraft Java, 127.0.0.1, 25565로 새로 만들어요.
  3. 새 주소 가져오기를 눌러요.
  4. 새 초대 링크 복사 → 믿는 친구에게만 보내요. 단톡방 공지나 공개 채널에는 올리지 마세요.

예전 주소는 없어졌으니 공격이 더는 우리 서버에 닿지 않아요.

10. 문제 해결

이런 일이 생기면이렇게 하세요
로그에 빨간 글씨나 ERROR가 많아요모드가 많으면 원래 그래요. "서버 열림!"까지 가면 정상이에요.
"켜지다가 멈췄어요"화면 전용 모드 때문이면 "이 모드를 빼고 다시 켤까요?"라고 물어봐요 → 예.
메모리 문제면 위쪽 글에 나온 대로 → 6번 ③에서 램을 바꾸고 다시 켜요.
그 밖의 경우 서버 폴더 열기 → crash-reports의 최신 파일을 도와줄 사람에게 보여 주세요.
"다른 서버가 이미 켜져 있어요"서버는 한 번에 하나만 켤 수 있어요. 켜져 있는 서버를 먼저 끄세요. 이 프로그램 밖에서 켜진 서버라면 프로그램을 닫았다가 다시 켜면 찾아서 꺼 줘요.
"서버가 켜져 있어서 지금은 할 수 없어요"■ 서버 끄기 → "꺼짐"이 된 뒤 다시 눌러요.
나도 못 들어가요 / "You are not white-listed"→ 4번 ①에서 닉네임 추가. 내 컴퓨터에서는 주소가 127.0.0.1예요.
친구가 접속을 못 해요먼저 콘솔 창에 ※로 시작하는 안내가 떴는지 보세요. 화이트리스트, 모드팩 버전, 마인크래프트 버전, 로그인 문제는 이유와 할 일을 알려 줘요. 안내가 없으면 차례대로 확인해요. ① 상태가 "서버 열림!"인가 ② ▶ 친구랑 하기로 켰나(혼자 하기 X) ③ 왼쪽 아래가 "Playit: 실행 중"인가 (아니면 → 1번) ④ 친구가 주소를 맞게 넣었나 ⑤ 친구 닉네임을 추가했나 (→ 4번 ①)
"Mod rejections", "mismatched mods"친구의 모드팩 버전이나 추가 모드가 서버와 달라요. → 4번 ③을 친구와 같이 다시 확인해요.
렉이 심해요→ 6번 ②
"디스크 공간이 모자라요"나온 숫자만큼 그 드라이브의 공간을 비우고 다시 만들어요. 다 쓴 서버는 servers_old 폴더나 오래된 백업을 지우면 공간이 많이 생겨요.
서버 만들기나 업데이트가 실패했어요인터넷 연결을 확인하고 같은 이름으로 다시 해 보세요. 실패한 폴더는 자동으로 정리되고, 업데이트 실패 때는 서버가 예전 그대로예요.
"프로그램이 이미 열려 있어요"작업 표시줄에서 이미 열린 창을 찾아 주세요. 프로그램은 한 번에 하나만 열려요.
"문제가 생겼어요" 창이 떠요내용을 캡처해서 도와줄 사람에게 보내 주세요. 기록은 _program\logs\manager-errors.txt에 남아요.
